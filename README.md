# AWS Bedrock Ticket Analytics

## Descripción del Proyecto

Proyecto de Big Data e Inteligencia Artificial desarrollado en AWS para el procesamiento, clasificación y análisis de tickets utilizando servicios serverless y Amazon Bedrock.

## Objetivo

Automatizar el análisis de tickets para identificar prioridades, clasificaciones y recomendaciones utilizando modelos de IA generativa.

## Servicios AWS utilizados

* Amazon S3
* AWS Lambda
* Amazon Athena
* AWS Bedrock
* AWS Glue
* IAM Roles

## Flujo de Arquitectura

1. Los archivos CSV de tickets son cargados en Amazon S3.
2. AWS Lambda procesa los datos.
3. Amazon Bedrock analiza el contenido de los tickets mediante IA generativa.
4. Los resultados son almacenados nuevamente en S3.
5. Amazon Athena permite realizar consultas analíticas sobre los datos procesados.

## Tecnologías utilizadas

* Python
* SQL
* AWS Cloud
* Generative AI
* Amazon Bedrock

## Resultados

* Clasificación automática de tickets
* Priorización de incidencias
* Procesamiento automatizado
* Reducción del tiempo de análisis manual
